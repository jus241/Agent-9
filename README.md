## Fonctionnement

Agent-9 est une application web simple développée en HTML, CSS et JavaScript.

L’utilisateur arrive sur une interface de connexion où il doit entrer un mot de passe secret.

- Si le mot de passe est correct : 
- Mot de passe: justin12345
  - l’utilisateur est redirigé vers une page secrète contenant un message caché.

- Si le mot de passe est incorrect :
  - l’utilisateur est automatiquement redirigé vers une page d’erreur.

Ce projet a été créé pour apprendre :

- la vérification de mot de passe,

- la création d’interfaces web,
